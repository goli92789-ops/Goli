# ربات سفارش زمان‌بندی‌شده‌ی مثقال (ایزی‌تریدر مفید)

از طریق تلگرام بگید چه مبلغی، از چه نمادی، ساعت چند بخره/بفروشه — ربات سر همون ساعت با
شبیه‌سازی مرورگر (Playwright) وارد `login.emofid.com` می‌شه و سفارش رو ثبت می‌کنه.

## ⚠️ قبل از هر چیز بخونید

- این ربات از **API رسمی** کارگزاری مفید استفاده نمی‌کنه (چون چنین چیزی برای مشتریان خرد
  وجود نداره) — به‌جاش مثل یک کاربر واقعی وارد سایت می‌شه و کلیک می‌کنه. اگر ظاهر سایت
  عوض بشه، ممکنه یک قدم بی‌صدا شکست بخوره.
- سلکتورهای مرحله‌ی ورود و ثبت سفارش بر اساس اسکرین‌شات نوشته شدن، نه بازرسی مستقیم صفحه.
  **اولین اجرا رو حتماً با یک مبلغ خیلی کم و چند دقیقه‌ی بعد تست کنید**، نه با مبلغ اصلی.
- بعد از هر اجرا (موفق یا ناموفق)، ربات یک اسکرین‌شات از نتیجه‌ی نهایی برایتان در تلگرام
  می‌فرستد — همیشه چک کنید که واقعاً همان چیزی ثبت شده که می‌خواستید.
- استفاده از این روش ممکن است با قوانین استفاده‌ی کارگزاری مغایرت داشته باشد؛ مسئولیت آن
  با شماست.

## راه‌اندازی روی VPS

### ۱. نصب Node.js و ابزارهای مرورگر

```bash
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo bash -
sudo apt-get install -y nodejs
```

### ۲. کپی پروژه و نصب وابستگی‌ها

```bash
git clone <آدرس ریپازیتوری> trade-bot
cd trade-bot/trade-bot
npm install
npx playwright install --with-deps chromium
npm run build
```

### ۳. تنظیم اطلاعات ورود

```bash
cp .env.example .env
nano .env
```

مقادیر لازم:
- `MOFID_USERNAME` / `MOFID_PASSWORD`: همان اطلاعات ورود ایزی‌تریدر
- `TELEGRAM_BOT_TOKEN`: در تلگرام به [@BotFather](https://t.me/BotFather) پیام بدید،
  `/newbot` بزنید، توکنی که می‌ده رو اینجا بذارید
- `TELEGRAM_ALLOWED_CHAT_ID`: به [@userinfobot](https://t.me/userinfobot) پیام بدید تا
  عدد chat id خودتون رو بگه؛ همون رو اینجا بذارید (فقط همین چت اجازه‌ی دستور دادن داره)

فایل `.env` هرگز نباید به گیت اضافه بشه (در `.gitignore` هست، دست نزنید).

### ۴. اجرای دائمی با systemd

```bash
sudo cp mesghal-bot.service /etc/systemd/system/
sudo sed -i "s|/root/trade-bot|$(pwd)|g" /etc/systemd/system/mesghal-bot.service
sudo systemctl daemon-reload
sudo systemctl enable --now mesghal-bot
sudo journalctl -u mesghal-bot -f   # مشاهده‌ی لاگ زنده
```

## استفاده (در تلگرام)

به ربات ساخته‌شده پیام بدید:

```
مثقال خرید 2000000 13:00
```

یعنی: ساعت ۱۳:۰۰ (اگر گذشته باشد، فردا همین ساعت)، به مبلغ ۲,۰۰۰,۰۰۰ تومان از نماد مثقال
بخرد. برای فروش، «فروش» به‌جای «خرید».

`/status` فهرست سفارش‌های زمان‌بندی‌شده‌ی هنوز اجرانشده را نشان می‌دهد.

## نکته‌ی مهم درباره‌ی واحد پول

قیمت‌ها در ایزی‌تریدر بر حسب **ریال** نمایش داده می‌شود. مبلغی که به ربات می‌دهید (مثلاً
2000000) بر حسب **تومان** تفسیر می‌شود و خودش ضربدر ۱۰ می‌کند تا تعداد واحد را از روی
قیمت لحظه‌ای محاسبه کند. عدد نهایی (تعداد واحد و مبلغ تقریبی) در پیام تأیید و در گزارش
بعد از اجرا نشان داده می‌شود -- همیشه چک کنید.
