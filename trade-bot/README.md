# ربات سفارش زمان‌بندی‌شده‌ی مثقال (ایزی‌تریدر مفید)

یه پنل وب ساده روی سرور بالا میاد؛ از مرورگر گوشی فرم رو پر می‌کنید (نماد، خرید/فروش،
تعداد واحد، ساعت) — ربات سر همون ساعت با شبیه‌سازی مرورگر (Playwright) وارد
`login.emofid.com` می‌شه و سفارش رو ثبت می‌کنه.

## ⚠️ قبل از هر چیز بخونید

- این ربات از **API رسمی** کارگزاری مفید استفاده نمی‌کنه (چون چنین چیزی برای مشتریان خرد
  وجود نداره) — به‌جاش مثل یک کاربر واقعی وارد سایت می‌شه و کلیک می‌کنه. اگر ظاهر سایت
  عوض بشه، ممکنه یک قدم بی‌صدا شکست بخوره.
- سلکتورهای مرحله‌ی ورود و ثبت سفارش بر اساس اسکرین‌شات نوشته شدن، نه بازرسی مستقیم صفحه.
  **اولین اجرا رو حتماً با کمترین تعداد ممکن و چند دقیقه‌ی بعد تست کنید**، نه با سفارش اصلی.
- بعد از هر اجرا (موفق یا ناموفق)، وضعیت و اسکرین‌شات نتیجه توی همون پنل ذخیره و نشون داده
  می‌شه — همیشه چک کنید که واقعاً همان چیزی ثبت شده که می‌خواستید.
- پنل روی اینترنت باز می‌مونه، پس رمز عبورش رو قوی و تصادفی انتخاب کنید.
- استفاده از این روش ممکن است با قوانین استفاده‌ی کارگزاری مغایرت داشته باشد؛ مسئولیت آن
  با شماست.

## راه‌اندازی روی VPS

### ۱. نصب Node.js و ابزارهای مرورگر

```bash
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo bash -
sudo apt-get install -y nodejs
```

### ۲. کپی پروژه و نصب وابستگی‌ها

```bash
git clone <آدرس ریپازیتوری> trade-bot
cd trade-bot/trade-bot
npm install
npx playwright install --with-deps chromium
npm run build
```

### ۳. تنظیم اطلاعات ورود

```bash
cp .env.example .env
nano .env
```

مقادیر لازم:
- `MOFID_USERNAME` / `MOFID_PASSWORD`: همان اطلاعات ورود ایزی‌تریدر
- `PANEL_USERNAME` / `PANEL_PASSWORD`: نام‌کاربری و رمز عبوری که خودتان برای ورود به
  پنل انتخاب می‌کنید (رمز قوی و طولانی بگذارید، این پنل از اینترنت در دسترس است)
- `PANEL_PORT`: پورتی که پنل رویش بالا می‌آید (پیش‌فرض 3000)

فایل `.env` هرگز نباید به گیت اضافه بشه (در `.gitignore` هست، دست نزنید).

### ۴. باز کردن پورت پنل در فایروال (در صورت نیاز)

```bash
ufw allow 3000/tcp
```

### ۵. اجرای دائمی با systemd

```bash
sudo cp mesghal-bot.service /etc/systemd/system/
sudo sed -i "s|/root/trade-bot|$(pwd)|g" /etc/systemd/system/mesghal-bot.service
sudo systemctl daemon-reload
sudo systemctl enable --now mesghal-bot
sudo journalctl -u mesghal-bot -f   # مشاهده‌ی لاگ زنده
```

## استفاده

از مرورگر گوشی به آدرس `http://<IP سرور>:3000` برید، نام‌کاربری/رمز پنل (همانی که در
`.env` گذاشتید) را وارد کنید، و فرم را پر کنید:

- **نماد**: پیش‌فرض «مثقال»
- **نوع سفارش**: خرید یا فروش
- **تعداد واحد**: همان عددی که مستقیم در فیلد «تعداد» فرم سفارش ایزی‌تریدر وارد می‌شود
- **ساعت اجرا**: اگر آن ساعت امروز گذشته باشد، فردا همان ساعت اجرا می‌شود

جدول پایین صفحه تاریخچه‌ی همه‌ی سفارش‌ها (در انتظار/انجام‌شده/ناموفق) را با لینک اسکرین‌شات
نتیجه نشان می‌دهد.

> اتصال پنل رمزنگاری‌شده (HTTPS) نیست مگر خودتان روی آن دامنه + گواهی TLS بگذارید؛ برای
> استفاده‌ی شخصی روی یک IP معمولاً کافی است، ولی اگر می‌خواهید امن‌تر باشد بگویید تا راه‌اندازی
> Caddy/nginx با HTTPS رایگان (Let's Encrypt) را هم اضافه کنم.
